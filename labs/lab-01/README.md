# ЛР1: Добыча корпуса документов

Тематика корпуса: **кино и сериалы**. Источники: русская Википедия и Кино-Театр.Ру.

| Путь | Что это |
|---|---|
| `report.tex`, `src/`, `styles/` | отчёт (LaTeX, шаблон преподавателя) |
| `Makefile` | сборка отчёта |
| `samples/` | 12 страниц, скачанных вручную: 7 из Википедии, 5 с Кино-Театр.Ру |

## Сборка

```
make pdf
```

`pdflatex` запускается два раза — иначе номера таблиц в ссылках останутся как `??`.

Пакеты (Debian/Ubuntu): `texlive-latex-base`, `texlive-lang-cyrillic`, `texlive-latex-extra`.
