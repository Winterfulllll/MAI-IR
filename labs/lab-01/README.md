# ЛР1: Добыча корпуса документов

Тематика корпуса: **кино и сериалы**. Источники: русская Википедия и film.ru.

| Путь | Что это |
|---|---|
| `samples/wikipedia`, `samples/filmru` | 13 страниц, скачанных вручную: 7 из Википедии, 6 с film.ru |
| `samples/kinoteatr` | 5 страниц Кино-Театр.Ру — первого кандидата во второй источник, от которого пришлось отказаться (закрыт от роботов) |
| `report/` | отчёт: LaTeX-исходники (шаблон преподавателя), `Makefile`, `report.pdf` |

Образцы Википедии и Кино-Театр.Ру используются в автотестах робота из ЛР2 (разбор UTF-8 и windows-1251).

## Сборка отчёта

```
cd report && make pdf
```

`pdflatex` запускается два раза — иначе номера таблиц в ссылках останутся как `??`.

Пакеты (Debian/Ubuntu): `texlive-latex-base`, `texlive-lang-cyrillic`, `texlive-latex-extra`.
