\CWHeader{Лабораторная работа \textnumero 1\\ \enquote{Добыча корпуса документов}}

Необходимо проанализировать корпус документов, который будет использован при
выполнении остальных лабораторных работ:
\begin{itemize}
    \item скачать примеры документов к себе на компьютер и указать в отчёте
          источник данных; источников в итоговом индексе должно быть не менее
          двух;
    \item ознакомиться с корпусом, изучить его характеристики. Из чего состоит
          текст? Есть ли дополнительная мета-информация? Если есть разметка
          текста, какая она?
    \item выделить текст;
    \item найти существующие поисковики, которые уже можно использовать для
          поиска по выбранному набору документов (встроенный поиск Википедии,
          поиск Google с ограничением на сайт);
    \item привести несколько примеров запросов к существующим поисковикам и
          указать недостатки в полученной выдаче.
\end{itemize}

В результатах работы должна быть указана статистическая информация о корпусе:
размер примеров \enquote{сырых} документов, количество документов, размер
текста, выделенного из \enquote{сырых} данных, средний размер документа и средний
объём текста в документе.
